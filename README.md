# Seattle Airbnb Data Analysis – Tableau

## Project Overview

This project analyzes Seattle Airbnb data using Tableau to explore pricing patterns, listing distribution, geographic trends, and revenue over time.

## Objectives

- Analyze Airbnb listing prices by number of bedrooms
- Examine the distribution of listings
- Analyze average prices by ZIP code
- Explore the geographic distribution of Airbnb listings
- Examine revenue trends over time
- Build an interactive Tableau dashboard

## Tools Used

- Tableau
- Microsoft Excel

## Dataset

The project uses Seattle Airbnb data containing information about listings, calendar activity, and reviews.

## Dashboard Analysis

The Tableau dashboard explores:

- Average Price by Bedroom
- Number of Listings
- Price by ZIP Code
- Geographic Distribution of Listings
- Revenue Trends Over Time
